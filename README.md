# 💈 Barber House

Landing page para uma barbearia moderna e elegante.

## 🚀 Tecnologias

- HTML5
- CSS3
- JS

## 📌 Projeto

Este projeto foi desenvolvido para praticar:

- Estruturação com HTML
- Flexbox
- CSS Grid
- Responsividade
- Organização de arquivos
- Design de landing pages
