# 💈 Barber House

Website moderno, elegante e responsivo desenvolvido para uma barbearia.

O projeto apresenta os serviços, preços, galeria de trabalhos, informações sobre a barbearia e um formulário de solicitação de agendamento integrado ao WhatsApp.

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- Design moderno e responsivo
- Navegação entre as seções
- Apresentação de serviços e preços
- Galeria de imagens
- Formulário de agendamento
- Seleção de data e horário
- Horários de funcionamento diferentes por dia da semana
- Domingo configurado como dia fechado
- Validação de nome, data e horário
- Modal de confirmação do agendamento
- Modal de avisos
- Envio da solicitação de agendamento pelo WhatsApp
- Favicon personalizado
- Layout adaptado para celular, tablet e computador

## 📱 Responsividade

O site foi desenvolvido para funcionar em diferentes tamanhos de tela:

- 📱 Celulares
- 📲 Tablets
- 💻 Desktops
